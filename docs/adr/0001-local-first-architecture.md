# ADR-0001: 纯本地架构 — 无后端、无云端

**Date**: 2026-09-25
**Status**: Accepted

## 背景

本系统面向学生群体，处理摄像头画面和体态数据。需要决定数据在哪里处理、存储在哪里。

## 决策

采用纯本地（浏览器内）架构：

- MediaPipe Pose WASM 在浏览器内推理，摄像头画面不上传
- 姿态评分数据存 localStorage，不上传任何服务器
- 无后端 API，可纯静态部署（GitHub Pages 即可）

## 理由

1. **隐私敏感**：学生群体对摄像头数据敏感度极高，纯本地是最大卖点
2. **零成本**：无需服务器、无需 API key、无需数据库
3. **零延迟**：本地 WASM 推理 ~30fps，无需网络往返
4. **Demo 阶段足够**：单文件 + CDN 引入 MediaPipe 即可跑通全链路

## 代价

- 无法跨设备同步数据（localStorage 绑定单浏览器）
- 无法做服务端趋势分析或多人对比
- 无法做用户系统/登录

如果后续扩展为完整产品，需要引入后端时，本架构的迁移成本是：新增 API + 数据迁移脚本，但本地推理逻辑不变。

## 否决的方案

- **本地推理 + 云端存趋势**：增加了后端复杂度和隐私合规成本，demo 阶段不值得
- **全云端推理**：延迟高、隐私风险大、服务器成本高，完全否决
